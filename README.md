## Overview
An Android application developed in Java and XML that connects to the official Traffic Scotland DATEX II feeds to provide real-time information on unplanned road incidents and current roadworks across Scotland. The app is designed for mobile devices running Android 8.0 (Oreo) or later (API level 26+).
